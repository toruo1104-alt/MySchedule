# MySchedule — 導入手順

個人用スケジュール管理Webアプリ。フロントは **GitHub Pages**、データは **Googleスプレッドシート**(GAS API経由)。
仕様は [docs/仕様書.md](docs/仕様書.md) を参照。ここでは**ゼロから使い始める手順**だけを書く。

アプリURL: **https://toruo1104-alt.github.io/MySchedule/**

## 初回セットアップ(約10分)

### A. GAS(データ側)の準備

1. **スプレッドシート作成**
   [sheets.new](https://sheets.new) で新規作成し、名前を付ける(例: `MySchedule`)。

2. **Apps Script を開く**
   メニュー「拡張機能」→「Apps Script」。

3. **コードを貼り付け**
   - 既存の `コード.gs` の中身を **`GAS.txt`** で全置換
   - 左の歯車(プロジェクトの設定)→「「appsscript.json」マニフェスト ファイルをエディタで表示する」にチェック → 現れた `appsscript.json` を **`appsscript_json.txt`** の内容で全置換

4. **初期化の実行と権限承認**
   エディタ上部で関数 `setupSpreadsheet` を選び「実行」。
   初回は権限承認ダイアログが出る → 自分のアカウントを選択 →「詳細」→「(プロジェクト名)(安全ではないページ)に移動」→ 許可。
   ※スプレッドシートとカレンダー(祝日取得用)への権限。自作スクリプトに自分が許可するだけなので問題ない。
   実行後、スプレッドシートに6シート(設定・区分・記録・日次・祝日・取込対応)と区分の初期値ができていれば成功。

5. **Webアプリとしてデプロイ**
   右上「デプロイ」→「新しいデプロイ」→ 歯車で「ウェブアプリ」を選択 →
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
   →「デプロイ」。表示された **WebアプリURL(…/exec)をコピー**しておく。

   > 「全員」にするのはアプリ(GitHub Pages)からの通信を受けるため。
   > データは次のトークンが一致しないと一切返さないので、URLだけ知られても読めない。

6. **トークンをコピー**
   スプレッドシートの「設定」シートにある **apiToken** の値(自動生成されたランダム文字列)をコピー。

### B. アプリ(フロント側)の設定

7. https://toruo1104-alt.github.io/MySchedule/ を開く(PCでもスマホでもOK。ブックマーク推奨)
8. 初回は「API設定」画面が開くので、手順5のURLと手順6のトークンを貼り付けて「保存して読み込み」
   ※設定はそのブラウザに保存される。別の端末で使うときは同じ入力を1回行う

## 更新の反映手順(コード修正時)

| 変更対象 | 反映方法 |
|---|---|
| フロント(`web/index.html` / `web/style.css` / `web/app.js`) | `git push` → GitHub Pages が自動反映(数十秒〜数分)。アプリをスーパーリロード(Ctrl+Shift+R) |
| GAS(`GAS.txt`) | GASエディタに貼り直し →「デプロイ」→「デプロイを管理」→ 鉛筆 → バージョン「**新バージョン**」→「デプロイ」(※新バージョンにしないと反映されない。URLは変わらない) |

> フェーズ5(D1移行)ブランチでは、フロント3ファイルは `web/` 配下に移動している。カットオーバー後は反映も `npx wrangler deploy` に変わる(`docs/構築手順書.md` 参照)。

例: 週ビュー機能の反映は、フロント3ファイル(`index.html`/`style.css`/`app.js`)を`git push`、`GAS.txt`はGASエディタの`コード.gs`へ貼り替え+上記の新バージョンデプロイ。

### Google Tasks連携の有効化(任意)

週ビューにGoogle Tasksの期限つきタスクを表示したい場合のみ設定する。未設定でも週ビュー自体は動作する(タスク欄に案内が出るだけ)。

1. GASエディタ左メニューの「サービス」(+)をクリック
2. 「Tasks API」を選択し「追加」(識別子は既定の`Tasks`のまま)
3. 貼り替え済みコードで新バージョンデプロイ
4. 初回実行時にTasks読み取りのOAuth承認が求められる場合がある

## ローカルプレビュー(開発用)

GAS・GitHubに反映せずに見た目・操作を確認できる(データはブラウザのlocalStorageに保存されるモック)。

1. このフォルダで `python -m http.server 8766` を起動(または Claude Code のプレビュー機能で `myschedule-preview`)
2. ブラウザで http://localhost:8766/preview/index.html を開く
3. モックデータをリセットしたいときは DevTools コンソールで `localStorage.removeItem('myschedule-mock')` → リロード

## 使い方(基本操作)

- **塗る**: 上部パレットで区分を選び、グリッドのセルをクリック or 矩形ドラッグ。ST(勉強)・FX(フレックス)は ▾ から内訳を選べる
- **消す**: **同じ区分を選んだまま、塗ってある所をなぞる**と消える(枠が赤くなる)。別区分を選んでなぞれば上書き。🧽消しゴムを使えば区分を問わず消せる
- **元に戻す**: 「↶ 元に戻す」ボタン or Ctrl+Z(直前30操作まで。月を切り替えると履歴は消えます)
- **パレットを隠す**: 「≡ 区分」ボタン(スマホでは最初から畳まれた状態で開きます)
- **日ごとのUB合計**: グリッド最下部に常時表示(スクロールしても固定)
- **メモ**(浜北・char など): セルを**右クリック** → 入力(同じ区分の連続枠にまとめて適用が既定ON)
- **有休・日メモ**(歓迎会など): 日付ヘッダをクリック
- **区分の追加・変更**: 「区分編集」ボタン(コードは追加後変更不可、名称・色などは変更可)
- **API設定のやり直し**: ⚙ボタン
- 保存は自動(右上に保存状態が出る)。設定(表示時間帯・要求時間など)はスプレッドシートの「設定」シートを直接編集 → アプリをリロード(フェーズ5カットオーバー後はD1コンソール。`docs/構築手順書.md` §5参照)

## セキュリティのメモ

- このリポジトリは Public(GitHub Pages 無料利用のため)。**コードのみ公開**であり、スケジュールデータ・トークン・GASのURLは含まれない
- apiToken が漏れた場合は、設定シートの値を書き換えるだけで即無効化できる(再デプロイ不要。アプリ側は⚙から新トークンを入れ直す)
